# Method Sources

These are method references, not a dependency list or permission to copy example artwork.

| Source | Adapted method |
|---|---|
| Motion Canvas | Generator-based, voiceover-synchronized 2D animation and live preview. |
| Theatre.js | High-fidelity keyframe choreography for HTML, SVG, React, and 3D values. |
| Remotion | Data-driven, reusable video composition in React. |
| HyperFrames | Seek-safe HTML, CSS, SVG, and GSAP blocks already used by this project. |
| Style Dictionary | One token source mapped consistently across renderers. |
| Carbon Design System | Productive versus expressive motion curves, spacing, type, grid, and icon systems. |
| IBM Plex | A coherent Sans, Serif, and Mono family for editorial and technical scenes. |
| Lucide | A consistent SVG icon grammar for non-brand controls. |
| D3 | Data-bound SVG and chart construction for factual graphics. |
| MetBrewer | Curated chart palettes; only use palettes whose contrast and category count fit the data. |
| Playwright visual comparisons | Same-environment golden-frame regression checks. |
| Third Brain v7 Skills | Non-equivalent ideation, explicit selection rationale, and fresh verification before completion claims. |
| Open Design | Anti-template rejection criteria, editorial hierarchy, restrained motion, and five-dimension craft critique. |

The canonical URLs, licenses, and integration status live in `configs/video_production_sources.json`.
