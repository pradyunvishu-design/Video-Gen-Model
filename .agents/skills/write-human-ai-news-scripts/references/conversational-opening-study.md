# Conversational Opening Study

Use this reference when selecting an opening mechanism or diagnosing a script that feels generic. It records transformed observations from 18 public transcript-backed AI Search videos. It does not preserve transcript passages, creator catchphrases, jokes, or persona.

## What repeated across the sample

- Product tests usually begin with a bounded verdict or visible output, then identify the product and the test the viewer is about to see.
- Demonstration-led episodes often let the artifact create the question before supplying context.
- Explanatory episodes frequently begin with a familiar user problem or an incumbent that appeared hard to beat, then introduce evidence that changes the comparison.
- Roundups preview several concrete developments quickly, but the best openings establish which development matters most instead of reading a flat list.
- Conversational energy comes from specific nouns, brief reactions after proof, plain-language translations, and quick movement into an example—not from slang or constant rhetorical questions.
- The most reusable teaching unit is: concrete change, plain explanation, visible proof, human consequence, honest limit, useful judgment.

## Original opening modes for this project

1. `verdict_first`: use when evidence supports a bounded judgment and a real comparison follows.
2. `demonstration_first`: use when the first visual can be a genuine output, failure, interface action, or source clip.
3. `relatable_friction`: use when a documented creator problem is easier to understand than the technical mechanism.
4. `context_reversal`: use when a prior assumption or incumbent makes the new evidence more meaningful.
5. `roundup_burst`: use for multi-story episodes, with one prioritized consequence and only the strongest previews.

Generate four candidates across at least three modes. Select on specificity, available proof, freshness relative to recent episodes, clarity of promise, read-aloud quality, and evidence coverage. The winning mechanism is a planning decision, not wording that must be copied into the final script.

## Patterns to reject

- the same stock line at the start of every weekly episode;
- a trailer-style adjective before the evidence;
- an opening that previews more stories than a listener can retain;
- a rhetorical question whose answer is already known but delayed for suspense;
- a personal test claim without a captured test ledger;
- repeated filler starters added merely to sound casual;
- imitation of a creator's phrase, joke, verbal tic, cadence signature, or persona.
