The requested `alphaparkinc/genpark-video-script-storyboard-generator-skil` URL did not resolve to a public GitHub repository during the 2026-08-23 review, so it was not installed or represented as source code. Only the independently verifiable Genspark workflow concepts above were used.

## Why these methods are combined

Blueprinting prevents fact-dump scripts. Promise alignment prevents hooks that overpromise. Section drafting keeps evidence scoped. Voice unification prevents stitched-together prose. A read-aloud edit fixes written-not-spoken language. An independent critic catches problems the writer rationalizes away.

The repository method catalog is `configs/video_production_sources.json`; keep it synchronized when another external method materially changes the pipeline.
