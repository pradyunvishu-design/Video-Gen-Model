# Motion Expert Hook Repair — Art Direction

## Beat

- Message: the useful upgrade is the workflow, not another model release.
- Proof object: a three-state workflow map using only narration-backed labels: request, plan, act, verify, result.
- Takeaway: judge the process that produces the answer.

## Concepts considered

1. **Proof-dominant console:** a large workflow panel leads, with the headline reduced to a supporting caption. Rejected because it delays the spoken hook.
2. **Model-to-workflow transformation:** a model block recedes while a process map expands. Rejected because the model block becomes a generic logo-like object and the transformation risks decorative motion.
3. **Editorial split with workflow map:** mixed-case hook typography leads on the left; a dense, diagrammatic workflow map provides the second read on the right. Selected for immediate comprehension, asymmetry, and narration-specific detail.

## Frame contract

- First read: “It isn’t the model.”
- Second read: request → plan → act → verify → result.
- Layout: 7/5 asymmetric split, locked camera, 116 px right safe area.
- Type: Inter for utility copy; restrained Georgia italic only for “the model.”
- Palette: near-black green neutral, warm off-white, quiet steel blue, moss, and clay. No decorative yellow, purple, glow, glass, or gradient.
- Motion: headline settles; panel enters once; route draws; states reveal in order; result lines resolve. Every move exposes structure.
- Source label: none, because this is an explanatory evaluation beat rather than source evidence.

## Second typography pass

- Remove the serif italic after held-out review identified it as too magazine-like.
- Keep the headline fully sans-serif and add a compact `MODEL → WORKFLOW` logic strip so the left side reads as part of the explanatory system rather than a standalone poster.
- Preserve the accepted workflow map, timing, camera, palette, and all other scenes.

## Pre-render critique contract

- Philosophy: must read as an editorial diagram, never fake product UI.
- Hierarchy: headline, process, result; no fourth focal group.
- Detail: borders and state markers must remain legible at mobile-size reduction.
- Function: every label comes from the evaluation narration.
- Restraint: no continuous motion, camera drift, spin, bounce, or decorative particles.
